# AI 英语学习教练组织设计（骨架 v0.1）

> **一句话**：一个常设的 AI 教练组织，学习者任何时刻唤起即练、任何时刻中断不丢进度；碎片时间按档位取用预切好的微任务；训练主轴不是背单词，而是在大量语境中反复遇到语块，把语感练成自动化反应。

> **项目归属**：本设计属独立项目 english-coach（/Users/mac/codes/english-coach）；文中引用的 specs/、proposals/、theory/ 路径均指 ai-native 理论仓（/Users/mac/ai-native），仅作版本锚引用，文件不在本项目内。设计所用机制的自带定义见 [kernel.md](kernel.md)——无需访问 ai-native 仓即可完整理解本设计。

## 一、命题与机制映射

用户三个要求，每个对应本仓一组既有机制，不是新发明：

| 要求 | 机制 | 来源锚 |
|---|---|---|
| 随时中断和继续 | 可恢复性不变量族的学习域实例化（L-TREE/L-NOLOSS/L-RESUME/L-REFORM）+ 每轮微落盘 + 会话自举 | 可恢复性提案 §二（2026-10-01）；生产局 §5.6（v0.1.2） |
| 充分利用碎片化时间 | B0/B2/B5/B15 四档微会话 + 预切任务队列（唤起零启动）+ 学习者仅三触点（唤起式非推送式） | 生产局 §5.7 触点表的对偶压缩；I-REFORM「随时唤起」 |
| 语感、语境优先 | 三源循环调度（新输入/语境复现/输出判定）+ 语块为最小记账单位 + 可编程语料织入复现 + I-DISC 判读分离 | 生产局 M8（I-DISC）；语块/间隔重复为教学法假定（见 §十二诚实声明） |

**定位**：这是生产局（软件生产）在「学习教练」域的特化——同款元策略（生成+门控+收敛），但人类触点从七压缩到三，因为学习场景天然高可逆（最大代价是学习者时间，无不可逆生产风险）。

## 二、组织结构：一锚、一官、两局

```
┌───────────────────────────────────────────────┐
│  学习者（goal-keeper，人类）——三触点：        │
│  T1 目标锁定（一次）/ T2 周度方向（2min）/ T3 喊停 │
└──────┬──────────────────────────▲─────────────┘
       │ 目标锚/难度反馈/周度确认   │ 周报与错题修复记录
┌──────▼──────────┐   ┌───────────┴─────────────┐
│ 教练官（常设 AI） │   │ 判读局（判定侧）          │
│ 主循环编排·单写者 │   │ 判读官（fresh，判定输出）  │
└──────┬──────────┘   │ 记忆官（语块间隔调度）     │
       │ 今日任务包    └───────────▲─────────────┘
┌──────▼──────────────────────┐   │ 复现集/判定结果
│ 语料局（输入侧·想象侧）        │───┘
│ 选材官（i+1 材料+织入复现语块） │
│ 陪练官（生成练习，不判定）      │
└─────────────────────────────┘
```

角色表（四要素借生产局 §10.7 格式）：

| 角色 | responsibility | authority | constraints |
|---|---|---|---|
| 学习者（人类） | 持学习意图与价值函数；练；三触点出场 | 接受/否决选材方向与配比大调；随时喊停 | 不自评语感（判读官的事）；不替 AI 枚举语境域 |
| 教练官（常设 AI） | 会话自举→取包→派发→收卷→微落盘→补切队列；监测难度失配与节奏 | `learner-state.md` 唯一写者；配比 ±10% 内自动微调 | 单写者；不改目标锚与难度档（学习者/触点职权）；禁推送式打扰——只应唤起 |
| 选材官（语料局） | 按难度带+语境域矩阵选/改/生成 i+1 材料；把复现语块织入新材料 | 写 `corpus/` | 织入密度上限（防材料不自然）；多样性下限；不写账本 |
| 陪练官（语料局） | 从近期输入与复现集生成练习（复述/造句/微对话/改写） | 只写练习包 | **不判定练习结果**（I-DISC） |
| 判读官（判读局，fresh） | 独立判定学习者输出；给母语者式反馈；错误入错题本 | 写 `error-book.md` 判定栏 | 不出题（I-DISC）；反馈优先讲自然度，不堆语法术语 |
| **独立标注官**（⚠️ v0.2 新增，归属待裁决） | 复核结构标注是否准确、织入是否自然 | 写 `chunk-ledger` 之外的标注复核栏 | **不由选材官自评**——状态表 §六 与特性树 L1-2「标注执行者」均要求标注与质检互不见上下文 |
| 记忆官（判读局） | 语块间隔调度；出「今日复现集」；难度带监测 | 写 `chunk-ledger.md` 调度栏 | 不生成材料；调度算法=可换配置 |

**降级形态（最小可行，能简单就别复杂）**：教练官一人兼选材/陪练/记忆三帽（单会话内），判读官保持独立会话。**I-DISC 是唯一不可降级的隔离**：出题的 ≠ 判卷的——自练自判会固化错误语感（死法 D4）。

> ⚠️ **v0.2 挂账（批次 6 经 RMM 反查发现）**：`独立标注官` 是否为第六个常设角色**待 goal-keeper 裁决**。批次 6 的建议是**不可挂判读官**——标注复核虽与判定同属「判别侧」，但判读官已由 I-DISC 锁定为「不接触出题上下文」，再叠加标注复核会让其同时接触选材与判读两侧，反而**破坏而非强化隔离**。三选项：① 新设第六角色；② 标注复核并入选材局的独立会话（同局不同会话）；③ 取消独立复核，改为规则校验。**未裁决前按 ② 的最小形态试行并显式记录其代价。**

## 三、可恢复性：随时中断、随时继续

四条候选不变量（可恢复性提案 §二）的学习域实例化：

```
L-TREE     学习任务树 = 目标锚 → 语境域 → 语块/技能叶节点，
           整棵树仅从 learner-state.md + chunk-ledger.md 可重建，不依赖任何会话上下文。
L-NOLOSS   学习进度只认账本不认对话——「上次聊到哪」不算进度，
           会话里发生过但未落盘的轮次视为可弃轮次。
L-RESUME   续学点 = 最后一次落盘的 session-log 行 + 下一步指针；
           任何中断的损失上界 = 当前未完成的一轮交互（≤30 秒量级）。
L-REFORM   教练组织可随时解散重建：凭状态档案 + 本设计文档即可完全恢复运行，
           不依赖任何个体（人或会话）的记忆或在场。
```

**微落盘节奏**（L-RESUME 的工程支撑）：不是会话结束才写，而是**每轮交互结束即更新** session-log 当前行——一轮 = 一个问答对。这是「随时中断」的真正含义：把损失上界压到一轮。

**会话自举协议**（教练官每次唤起执行，无守护进程）：

```
① 读 learner-state.md（目标锚/难度档/下一步指针/队列水位）——不依赖对话记忆
② 读 chunk-ledger.md 的「今日复现集」段
③ 按学习者声明的时间档（默认 B5）从预切队列取包；队列空则即时切一个（降级：多等半分钟）
④ 开练；每轮结束微落盘
⑤ 会话末：更新下一步指针 + 队列水位；低于水位线 → 登记补切任务（下次唤起前完成即可，不阻塞当前会话）
```

## 四、碎片适配：四档微会话与预切队列

### 4.1 时间档位（微任务的切片规格）

| 档 | 时长 | 典型场景 | 形态 | 交互轮数 |
|---|---|---|---|---|
| B0 | 不定 | 做饭/走路/通勤 | 纯听或影子跟读（零交互，离线后补一行日志） | 0 |
| B2 | ≤2 分钟 | 排队/电梯 | 复现快答：语块闪答/单句改错 | 1–3 |
| B5 | 3–5 分钟 | 等车/间隙 | 微输入：一段 i+1 短文或对话 + 理解检查 | 2–4 |
| B15 | 10–15 分钟 | 午休/整段通勤 | 完整微闭环：输入 → 复现 → 输出判定 | 5–8 |

### 4.2 唤起协议（学习者的全部界面）

`继续`（默认档续学）｜`2分钟`/`5分钟`/`15分钟`（指定档）｜`只要听`（B0）｜`太难了`/`太简单了`（难度反馈，即时降/升档）｜`停`（Safe Halt：当轮作废，已落盘全保留）。

### 4.3 预切任务队列（零启动成本的关键）

教练官维护分档位的「即取即用」微任务包（每档水位线 ≥2 个）：

```
## 预切队列
### B2
1. [复现] 语块闪答：上周错题本 3 条（3 轮）
### B5
1. [输入] 语境域=工作邮件：短文约120词，织入复现语块×3
### B15
1. [循环] 输入→复现→输出 微闭环（会议发言域）
```

学习者唤起时**不现场生成、不问问题**，直接取队头开练——碎片时间的敌人是启动成本，不是学习难度。补切是后台动作（语料局），永不阻塞唤起。

## 五、语感循环：三源调度与可编程语料

### 5.1 记账单位：语块，不是单词

语块 = 搭配/短语/句式/习语等 2–6 词的自然共现单位（如 *make an informed decision* / *that said* / *the jury is still out*）。**以语块为最小记账单位，是语感路线与词汇量路线的分水岭**——语感是对「什么搭配自然、什么场合说什么」的隐性预期，单位必须是共现群而非孤立词。

### 5.2 三源循环（调度配比，初始值可调）

| 源 | 初始占比 | 做什么 | 谁做 |
|---|---|---|---|
| 新输入 | ~55% | i+1 可理解输入：按难度带+语境域选/生成材料，读或听，配理解检查 | 选材官 |
| 语境复现 | ~25% | 旧语块**在新语境中再遇到**（不是闪卡）：选材官把「今日复现集」织入新材料 | 记忆官调度→选材官织入 |
| 输出练习 | ~20% | 复述/造句/微对话/改写；判读官独立判定+母语者式反馈 | 陪练官出题→判读官判定 |

**可编程语料**是 AI 教练相对人类教练与背词 App 的核心差异化：语料是生成的，所以「间隔重复」可以从闪卡形态升级为**自然重遇**形态——今天读的新文章里，恰好织入了你上周学的五个语块。语感正是这样形成的：同一模式在足够多的不同语境中反复出现后，处理自动化。

### 5.3 判读官的反馈形态（语感落地的最后一公里）

三栏式，优先讲自然度不讲语法术语：

```
你写的：     We will discuss about the plan tomorrow.
母语者会写：  We'll discuss the plan tomorrow. / Let's talk through the plan tomorrow.
差别一句话：  discuss 是及物动词，直接跟宾语——加了 about 是典型中式痕迹。
```

错误分两类入错题本：**错**（语法/用词错误）与**不自然**（语法对但母语者不这么说）——后者是语感训练的主战场。**修复验证**：错题条目在后续复现中再次出现，答对即标记修复（对齐「行为可验证改变」——同类错误第二次不再犯，才算学会）。

### 5.4 难度带与语境域（选材的两根轴）

- **难度带**：L1–L5 五档（T1 定级 + 理解率滚动校准：每段输入配 1 个理解检查，滚动理解率 <70% 降档、>98% 升档建议）。材料始终钉在 i+1：跳一档够得着，不跳档。
- **语境域矩阵**：从目标锚派生（如：工作邮件/会议发言/闲聊/新闻/技术文档），主域 ~60%，辅域各 ≥10% 下限（防语料同质化，死法 D7）。

## 六、门禁与度量

### 6.1 四层仪表盘（指针式，以账本为准）

| 层 | 指标 |
|---|---|
| 收敛 | 输入量增速 / 语块账本规模与熟化分布（生:半熟:自动化）/ 预切队列水位 |
| 质量 | 输出判定通过率 / **错题修复率（同错二犯率，核心指标）** / 理解率带内占比 |
| 价值 | 学习者自评流畅感（周报 1 题）/ 真实使用事件（工作/生活里实际用上了） |
| 组织 | 唤起响应时延 / 会话完成率 / **中断后续接成功率（L-RESUME 实测）** |

### 6.2 死法总表（词典序）

| # | 死法 | 机理 | 对策 |
|---|---|---|---|
| D1 | 打卡化（Goodhart） | 优化「会话数/连续天数」，语感没涨 | 多指标对冲：会话数涨但修复率与输入量不涨 = 黄灯；价值层季度校验 |
| D2 | 难度失配 | 过难→挫败弃学；过易→零增益 | 难度带锚定 + 理解率自动校准 + 「太难/太简单」一键反馈 |
| D3 | 进度蒸发 | 状态只在对话里，会话压塌即丢 | L-TREE/L-NOLOSS/L-RESUME + 每轮微落盘（本设计核心约束） |
| D4 | 自练自判（I-DISC 违反） | 陪练官判自己的题→错误语感固化 | 判读官独立会话 fresh 判定；错题双栏（出错/修复）追踪 |
| D5 | 零食化 | 碎片时间只做最轻的 B2，回避输出 | 输出配比周下限 ~15%；教练官周报点破；B15 引导 |
| D6 | 触点压垮（学习者带宽破产） | 频繁确认/推送→烦→弃用 | 三触点极简 + 默认零推送，唤起式（pull）服务 |
| D7 | 语料同质化 | 选材窄化→语感只对单一文体生效 | 语境域矩阵多样性下限 |
| D8 | 织入痕迹 | 复现语块织入太密/太生硬→材料不自然，学歪 | 织入密度上限（每百词目标语块数封顶）+ 判读官抽查材料自然度 |

### 6.3 政策继承块

```yaml
policies:
  - id: state-ledger-only          # 进度只认账本不认对话（L-NOLOSS）
  - id: micro-checkpoint-per-turn  # 每轮交互结束即微落盘（L-RESUME）
  - id: no-flashcard               # 复现=新语境重遇，禁孤立闪卡形态
  - id: chunk-as-unit              # 最小记账单位=语块非单词
  - id: discriminator-not-generator # 判读官≠出题者，独立会话（I-DISC）
  - id: budget-graded-slicing      # 微任务按 B0/B2/B5/B15 档切片
  - id: queue-watermark            # 预切队列水位线，补切不阻塞唤起
  - id: touchpoint-minimal         # 三触点+零推送，唤起式服务
  - id: difficulty-band-anchor     # 材料钉 i+1 难度带，理解率自动校准
  - id: diversity-floor            # 语境域矩阵多样性下限
  - id: safe-halt-on-stop          # 「停」即安全停机，已落盘全保留
```

## 七、落盘物与文件布局

运行时是一个独立 OKF 子包（可放本仓 `runtime/` 下，也可独立目录/仓库）：

```
english-coach/
├── learner-state.md   # 状态档案：目标锚/难度档/语境域矩阵/下一步指针/预切队列
├── chunk-ledger.md    # 语块账本（**事实栏/派生栏分离**，v0.2 依批次 9 合账裁决）：
│                      #   事实栏（合账时按 OR 并集，冲突不得静默丢弃）：chunk# | 语块 | 语境标签 | 首遇 | 复现史
│                      #   派生栏（合账后由纯函数重算，不采信任一方）：状态(生/半熟/自动化) | 下次调度
│                      #   ⚠️ 派生栏混入事实栏会导致 LWW 静默丢弃「需复核」信号 → A3 队列饿死且仪表盘不可见
├── session-log.md     # 微会话日志：| 日期 | 档位 | 形态 | 输入量 | 判定结果 | 微落盘轮数 |
├── error-book.md      # 错题本：| # | 我写的 | 母语者会写 | 差别 | 类别(错/不自然) | 修复标记 |
├── weekly-review.md   # 周度触点材料（教练官起草，2 分钟过目，默认延续）
└── corpus/            # 语料库（按语境域分目录）
```

`learner-state.md` 的「下一步指针」就是 L-RESUME 的续工点；六件产物即 I-REFORM 的全部重建输入。

## 八、完成标准与边界

**本提案交付**：组织结构 + 四组机制（可恢复/碎片适配/语感循环/门禁度量）+ 账本模板 + 死法对策。

**明确不含**：① 具体语料与练习内容；② 语音交互实现（B0 档闭环方案见未决项）；③ 教学法文献核实（见 §十二诚实声明）；④ 多学习者/班级形态（本版单人）。

**下一步路径**：骨架获批 → 实例化一次真跑（运行档案留档本项目）→ 首周读数（中断续接成功率/修复率/留存）→ v0.2。运行时载体（App，iOS/macOS 先行、五平台路线）设计见 [App设计](app-design.md)。

## 九、判断基准三问

- **维度**：① 中断恢复实测——随机时刻杀会话，续学点判定零争议、损失不超一轮；② 语感指标走得动——错题修复率与输入量是否随周递增；③ 学习者留得住——触点负担与启动成本是否低到不弃用（唤起响应时延、周留存）。
- **死法**：最可能是 D6（触点压垮→弃用，产品死法）与 D2（难度失配→挫败，教学法死法）的合谋——组织再优雅，学习者不用就是死。次之 D1 打卡化：指标好看、语感没涨的自欺。D3 进度蒸发是被本设计结构性堵死的，但要靠实测确认微落盘节奏真的被执行。
- **可逆性**：全部产物是 md 账本，git 可回退；调度配比/档位/语境矩阵全是可调参数。唯一不可逆的是学习者的时间——所以新形态先在 B15 内小试、周报再放量。
