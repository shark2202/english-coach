# 业务目标模型（BOM）v0.3（已冻结）

## 零、本卡的口径适配（明示，不静默套用）

原书卡内规定：最高层业务问题必须直接关系**钱**（增加收入 / 降低成本 / 合规），否则继续向下钻。本项目是**单人自用**工具，无收入侧。按卡内**成本类问题**分支处理，将「钱」落点映射为：

> **个人时间成本** = 理解一段专业论述所投入的时间 + 为确认「自己没读错」而付出的**二次查证时间**（查词典、比对多个译文、回读）。

此适配已明示记录，后续所有目标与度量均以此为准。若此映射不成立，本模型须整体重做。

## 一、业务问题（图 3-9 式层次下钻，每层成对）

每层先问「为什么这是一个问题」，直到答案落到时间成本。

| 层 | 问题 | 为什么它是问题（下钻依据） |
|---|---|---|
| **P0** | 读懂一段专业英文论述的成本，是读同题材中文材料的**三倍以上** | 成本直接落在时间上：读原文 + 查证 + 与译文对照，三份成本叠加 |
| **P1** | 为什么必须付三份成本，不能一次读懂 | 因为**读英文时大脑自动套用中文结构**，理解结果与作者原意不一致，不外部对照就无法确认 |
| **P2** | 什么阻止「一次读懂」的实现 | 因为**训练材料以英汉一对一对照为核心**（翻译对、词表、句型替换），不存在训练「英汉不等价结构」的机制 |
| **P3** | 为什么训练材料是那样的 | 因为**默认英语与中文可一一对应**。该假设在日常/商务口语上大体成立，故无人专门训练它；**但在哲学与管理文本上系统性失效**——限定嵌套、情态立场、名词化结构、术语历史层累，这些是结构性语言现象，不是词表问题 |
| **P4** | **（v0.3 新增）** 为什么材料编排会「越用越不合身」 | 因为**编排依据的是一个静态难度档位**，而学习者的能力是**多维、各自漂移、且会退步**的动态状态。系统按过期画像持续推送材料，学习者感知到「没用」→ 弃用 |

**问题性质归类**：P0 成本类；P2 机制缺失类（回溯其成本影响仍落在 P0 的时间成本上）。

## 二、业务目标（必须含具体数字与时间点；禁用百分比变化）

> **范围限定（v0.2 裁决）**：本轮目标限于**二手学术材料**（综述、教材、书评、期刊论文），方法验证有效后再上探原典。哲学与管理**并行**，不设先后。
> **数字状态（v0.2 裁决）**：G0–G3 的当前级别估计值经 goal-keeper 确认**大致接近真实**，采信为基线，卡内「具体数字」纪律已满足，本模型冻结。

| # | 对应问题 | 目标陈述（当前级别 → 目标级别） | 时间点 | 状态 |
|---|---|---|---|---|
| **G0** | P0 | 读完一篇 **2000 词**专业英文（哲学/管理）并确认理解正确的总耗时：**当前 60–90 分钟** → **目标 ≤ 45 分钟** | 90 天 | ✅ 基线已确认 |
| **G1** | P0/P1 | 其中**二次查证时间**（查词典 / 比对译文 / 回读）占比：**当前 40–60%** → **目标 ≤ 20%**（即 ≤9 分钟/篇） | 90 天 | ✅ 基线已确认 |
| **G2** | P1 | 读后能**正确复述论证结构**（前提 → 结论 → 限定范围 → 立场强度）的比例：**当前 < 30%** → **目标 ≥ 80%** | 90 天 | ✅ 基线已确认 |
| **G3** | P1/P2 | 每次阅读中**限定/情态误读**发生次数（把 hedging 读成断言、把限定读成无条件、把术语读成常见义）：**当前 ≥ 3 次/篇** → **目标 ≤ 1 次/篇** | 90 天 | ✅ 基线已确认 |
| **G4** | **P4（v0.3 新增问题）** | **能力画像的新鲜度**：系统用于编排材料的画像，反映的是**最近一次判定记录**而非初始估计——陈旧画像（>14 天无更新）导致的材料编排次数：**当前 N/A（能力不可观测）** → **目标 0 次**（画像过期即降级为通用兜底包，不按过期画像编排） | 持续 | 新增，基线待批次 2 定义后测量 |

## 三、产品概念（解决方案愿景 · 主要功能列表）

以下每个功能均可**回溯到业务问题**（卡内完成标准之一）。

| # | 功能区域 | 内容 | 回溯问题 |
|---|---|---|---|
| **F1** | **目标语料域** | 哲学（形而上学 / 认识论 / 伦理学 / 分析哲学）+ 管理（战略 / 组织理论 / 财报 / 咨询话语）两大专业域及其子域矩阵 | P3 |
| **F2** | **不可直译结构标注层**（新增机制） | 材料入库/生成时，对其中**英汉不等价的结构**打标：名词化链、限定嵌套、情态与立场标记（hedging）、术语固定对译陷阱、语域标记。标注是**一等字段**，不是批注 | P2 / P3 |
| **F3** | **结构级理解判定**（新增机制） | 输入端的判定对象不是词汇理解率，而是**论证结构**：读完一段后回答「这句限定管到哪」「这是断言还是让步」「论证的前提是什么」，由独立判读官判定 | P1 / P2 |
| **F4** | **回译对照视图**（可选） | 并置英文原文 / AI 参考译文 / **不可直译标注**；不追求唯一译文，暴露「此处多译/不可译」 | P1 |
| **F5** | 三源循环（沿用，配比重估） | 语块复现 + 输出判定沿用既有设计；**输入源（55%）须让位一部分给 F3 的结构理解训练** | P2 |
| **F6** | 可恢复性底座（沿用） | 账本优先 / 每轮微落盘 / 断点续学 / 跨设备无缝切换 | P0（成本：碎片时间不可用则一切归零） |
| **F7** | **学习者能力画像**（v0.3 新增） | 多维能力状态的**派生与记账**：每个维度独立记分、独立调度、独立衰减；难度锚随维度漂移；画像陈旧即降级，不按过期画像编排 | P4 → G4 |
| **F8** | **判定难度锚**（v0.3 新增） | 每道理解判定题携带难度锚与作答者的当次掌握度对照——防止「题变简单导致指标假性达标」 | P4 → G2 / G3 |

**指导原则（对解决方案的一般性约束）**：

- **GP1** 账本是唯一事实源，App 可整体替换——进度不绑死在任何壳上。
- **GP2** 单机是基线形态，联网同步是可选叠加层；同步失效不降级单机功能一分。
- **GP3** 默认零推送，三触点极简——唤起式服务，保护动机带宽。
- **GP4** 训练对象是**结构与语境**，不是词表——这是本轮目标重锚带来的第一指导原则。
- **GP5** I-DISC：出题者 ≠ 判读者，两类生成互不见上下文。
- **GP6** 材料难度钉 i+1；理解结构随域与水平变化，不是一把尺。

## 四、成功标准（直接度量优先，间接度量须跟踪假设）

| # | 度量 | 类型 | 关联目标 | 跟踪的假设 |
|---|---|---|---|---|
| **SM1** | 结构理解判定正确率（论证结构题正确比例） | 直接 | G2 / G3 | 假设判定官判定可靠——**该假设仅在 T2 云判定或 T1 本地模型成立时有效；若降级到 T0 预嵌，此指标失真**（对齐「降级可见性」原则） |
| **SM2** | 不可直译结构识别率：遇标注结构能否指出其存在与含义 | 直接 | G1 / G2 | 假设「能指出」可迁移到「真实阅读中能察觉」——若练习材料结构密度低于真实阅读材料则失效 |
| **SM3** | 查证收敛率：每篇所需二次查证时长占比 | 直接 | G0 / G1 | 假设查证时长可被如实记录——若学习者回避记录则失真 |
| **SM4** | 真实使用事件（间接）：**没打开任何译文就把一段专业论述读完**的天数 | 间接 | G0 | **假设应用时的理解强度 ≥ 训练时的理解强度**。若训练材料难度低于真实阅读材料，此指标会系统性高估 |
| **SM5** | **能力维度漂移可见性**（v0.3 新增）：各维度掌握度的**变化轨迹**（近 4 周斜率），含负斜率 | 直接 | G4 | 假设判定记录连续且未大量降级——若长期只用 T0 预嵌判定，掌握度斜率不可信（同 SM1 的降级假设） |
| **SM6** | **判定难度分布**（v0.3 新增）：正确率上升时，题目的平均难度锚是否同步上移 | 直接 | G2 / G4 | 这是 SM1 的**证伪指标**——正确率涨而难度锚不涨，即判定假性达标 |

**完成标准自检（卡内表 3-2）**：四类元素齐全 ✅；每层问题/目标成对 ✅；目标含具体数字与时间点 ⚠️（数字为待确认估计值）；每个功能回溯到业务问题 ✅；成功标准获得重视 ✅（SM1/SM3 挂在 P0 成本上，而非只关注 F2/F3 功能本身）。

### 5.1 v0.3 新增死法登记（须回写既有死法总表）

本次分析发现两个既有死法总表未覆盖的失败模式，按 kernel §7「死法预演」机制登记。**本轮仅登记，未直接改写 org-design §六.2 与 app-design §九**——两份是已评审的提案，内容变更须经 goal-keeper：

| 拟登记 | 死法 | 机理 | 拟对策 |
|---|---|---|---|
| **D9（org-design §六.2）** | **画像漂移** | 材料按过期能力画像编排 → 学习者感知「越用越没用」 → 弃用。是死法 D2（难度失配）与 D6（触点压垮）的合体——D2 是材料太难/太易，D9 是**系统不知道你变了** | 画像必须由判定记录派生而非人工设定；画像陈旧 >14 天即降级为通用兜底包；每周触点显式呈现画像变化轨迹供裁决 |
| **A13（app-design §九）** | **判定假性达标** | 判定题难度锚不随能力上移 → 正确率虚高 → 指标漂亮但能力未涨。这是死法 D1（打卡化）的工程变体 | 每题携带难度锚；SM6 作为 SM1 的证伪指标强制同框呈现；正确率上升而难度锚不动时，仪表盘主动打黄灯 |

### 5.2 批次计划调整（v0.3）

**批次 2（数据契约）的输入契约已变更**：原计划冻结六件账本字段，现须额外冻结 **能力维度定义**——它决定数据字典里有哪些实体、哪些字段可派生、哪些必须记账。批次 2 的紧迫性因此上升：**能力维度不定，状态表（批次 3）与决策表（批次 4）无法开工**。

## 六、未决项（留待 goal-keeper / 学习者裁决）

**已关闭（2026-10-14 裁决）**：① 目标水平 → 分层推进，先二手学术材料；② 领域优先级 → 哲学与管理并行；⑤ 数字基线 → 采信估计值。

**仍开放**：

1. **材料来源策略**（继承 org-design 未决项 2）：自带材料（贴目标锚，但需你持续供给）/ AI 生成（自由度高但真实性存疑）/ 版权摘编（合规风险）——哲学与管理文献均受版权约束。**本轮优先级最高的开放项**：F2 不可直译标注的可靠性直接依赖材料质量。
2. **训练偏输入还是偏输出**：以阅读理解为主，还是也要练表达？决定 F5 三源循环的配比。
3. **二手材料的「二手」边界**：教材/综述算二手，但期刊论文与预印本接近一手；课文的语域稳定性与论文差异很大。需在校准语料库时明确。
4. **License**（继承 README 挂账）：对外分发前必须定。
5. **原典上探的触发条件**：方法验证到什么程度算「跑通」，才值得投入原典？建议挂在批次 4 决策表产出后，用 SM1/SM2 的实际读数定线。
6. **能力维度的初始划分**（v0.3 新增，批次 2 输入契约）：拟设 6 维——术语识别 / 句法结构解析 / 不可直译结构识别 / 论证结构还原 / 语域文体识别 / 立场情态判读。**各维度的定义边界与是否独立记分待裁决**——尤其「不可直译结构识别」与「句法解析」在名词化链上边界重叠，需先定义清楚再冻结数据字典。
7. **目标中途重定机制**（v0.3 新增）：90 天固定目标与能力漂移冲突——重定由谁触发（系统建议 / 学习者裁决）、触发阈值多少、重定几次上限。倾向：**系统只呈交证据与建议，重定由学习者在周度触点裁定**（对齐 goal-keeper 机制，AI 只呈交选项与证据）。
8. **能力衰减的检测窗口**（v0.3 新增）：多久不练算「开始退步」？与语块遗忘曲线是同一套还是分开一套？涉及记忆官调度算法的可换配置边界。
