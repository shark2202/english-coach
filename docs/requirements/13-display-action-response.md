# 显示-动作-响应模型 v0.1

> **图例**：元素表三段——**描述**（ID + 一句「是什么/做什么」）· **显示**（前提条件 → 显示方式）· **行为**（前提条件 + 用户动作 → 系统响应）。
> 前提条件来源：`04-state-table.md`（8 张状态表）、`05-state-diagram.md`、`07-decision-tree.md`、`03-data-dictionary.md`（DD 字段）、`app-design.md` §五（设备形态）。

## 零、E1 屏幕筛选（哪些屏幕需要 DAR）

| 规范屏幕 | 建 DAR | 元素数 | 判定理由 |
|---|---|---|---|
| S1 首启引导 | ✅ | 1 | 目标锚输入是数据驱动的（写入 DD101 目标锚对象） |
| S2 唤起与开练 | ✅ | 5 | 续学点、队列水位、同步/判定双槽四类数据驱动 |
| S3 会话 | ✅ | 3 | 练习项字段随档位与音频可用性变化 |
| S4 判定反馈 | ✅ | 3 | 结果随 DD203/DD205 四值组合变化 |
| S5 队列空提示 | ✅ | 2 | 四条失败/降级分支各有不同文案 |
| S6 今日复现 | ✅ | 1 | 复现态标记由语块调度派生 |
| S7 错题本 | ✅ | 2 | 四态列表 + 修复验证标记 |
| S8 错题详情 | ✅ | 2 | 同类错误对照 + 修复验证记录 |
| S9 周度复盘 | ✅ | 2 | 周报草稿随周数据派生；确认动作改写状态 |
| S10 仪表盘 | ✅ | 3 | SM1–SM6 六项 + 证伪灯 + 降级占比 |
| S11 状态与设置 | ✅ | 4 | **挂账一、二的主要落点**；元素数 4 = 7±2 下界内，无需分区 |
| S12 阅读检视 | ✅ | 1 | 结构标注呈现随标注版本变化 |
| S13 队列检视 | ✅ | 2 | 水位与难度锚随调度重算变化 |
| **合计** | **13/13** | **33** | 每屏元素数 ≤5，全部落在 7±2 内（最大 5 = S2）。**33 的构成**：逐屏专属元素合计 31 + 跨屏全局元素 2（`ELMT_0101` 同步槽 / `ELMT_0102` 判定槽，常显于全部屏幕状态行，不归属任何单屏） |

**不建 DAR 的两项（明示）**：

1. **跨屏错误屏**——TTS 失效、ASR 失效、Keychain 失效、云 provider 报错、账本文件 I/O 失败。卡内 E1 明文「排除错误屏幕（交给 DAR）」——它们的**呈现方式已分别并入** `ELMT_0601`（队列空/离线提示）、`ELMT_1203`（密钥可用性）、`ELMT_0401`（音频可用性）的显示前提条件，不另建屏。
2. **静态元素**——栏标签、按钮文字、图标、单位说明。卡内 B 段「不要给静态元素建模」。

**一处刻意的不建表**：`ELMT_0602`（补切登记反馈）本可并入 `ELMT_0601`，但「登记了补切任务」是 `07-decision-tree.md` §三 的显式产物且学习者会反复回来看，故单列。**这是本表唯一一处为可读性而拆分的元素。**

## 二、ELMT_0101 · 状态行·同步状态段【全局】

**描述**：常显于全部 18 个屏幕框状态行左槽位的同步状态指示。四态 + 四条失败原因分支。**这是本模型中仅有两张跨屏元素表之一**（另一张为 `ELMT_0102`）——因为死法 A10 的对策「不假装新鲜」要求它无处不在。

**显示**

| 前提条件 | 显示 |
|---|---|
| 总是 | 单槽位常显；**不折叠、不省略、不因屏幕类型而隐藏**（A10：不得隐藏） |
| DD703 = 单机 | `◍ 单机 · 本机账本，功能完整` |
| DD703 = 同步中 | `◐ 同步中 · 账本至 14:20（iPhone）` |
| DD703 = 已同步 | `✓ 已同步 · 14:20（MacBook）` + 相对时刻「2 分钟前」 |
| DD703 = 同步失败 且原因 = 本地存储不足 | `⚠ 同步暂停 · 存储不足 · 账本停留在 14:20（iPhone）` |
| DD703 = 同步失败 且原因 = 云服务未登录 | `⊘ 已转入单机模式 · 云服务未登录 · 账本停留在 14:20（iPhone）` |
| DD703 = 同步失败 且原因 = 存在未解冲突 | `⚠ 同步挂起 · N 项待裁决 · 账本停留在 14:20（iPhone）` |
| DD703 = 同步失败 且原因 = 不可判定 | `⚠ 同步失败 · 账本停留在 14:20（iPhone）` |
| 任一非单机态 | **必带 DD704 同步至时刻 + DD705 来源设备**，两项均不得为空 |
| 失败态 | `⊘` 与 `⚠` **不同图标**：⊘ = 同步已关、单机在工作；⚠ = 同步想工作但失败了 |

**行为**

| 前提条件 + 用户动作 | 系统响应 |
|---|---|
| 任意态 + ⟨点击状态行⟩ | 下钻至 S11「状态与设置」的同步区块（I10 / M8）。**不弹窗、不遮罩** |
| 同步失败（云服务未登录）+ ⟨点击状态行⟩ | 下钻至 S11 并展开「登录以恢复同步」区块，`ELMT_1201` 高亮 |
| 同步失败（未解冲突）+ ⟨点击状态行⟩ | 下钻至 S11 并展开 `ELMT_1202` 冲突裁决清单 |
| 同步失败（存储不足）+ ⟨点击状态行⟩ | 下钻至 S11 并展开清理指引 |
| 同步失败（不可判定）+ ⟨点击状态行⟩ | 下钻至 S11 并展开「立即重试」 |
| 任意态 + ⟨系统后台重试成功⟩ | 槽位就地更新为 `✓ 已同步 · <新时刻>（<新设备>）`。**不通知、不震动、不改变屏幕** |
| 同步失败态 + ⟨系统后台重试仍失败⟩ | 槽位**保持不变**。状态表 §八「重试不提升状态」——失败态必须由一次成功同步才能离开 |

**下一处能去哪**：S11 状态与设置（唯一去向）。S11 的四态明细与本元素同源，不重复定义。

## 三、ELMT_0102 · 状态行·判定级别段【全局 · 挂账二载体】

**描述**：常显于状态行右槽位的当前判定级别与待复核计数。**这是死法 A9「离线判定质量塌陷」的可见化载体**。

**显示**

| 前提条件 | 显示 |
|---|---|
| 总是 | 单槽位常显，紧随 `ELMT_0101`；不折叠不省略 |
| 最近一次判定 DD204 = T0 | `判定 T0 · 预嵌` |
| 最近一次判定 DD204 = T1 | `判定 T1 · 本地` |
| 最近一次判定 DD204 = T2 | `判定 T2 · 联网` |
| 待复核计数（DD203 = 待复核 的未补判行数）= 0 | 槽位止于级别词，无追加 |
| 待复核计数 > 0 | 追加 `· 待复核 N`，**槽位文字转警示色** |
| 最近一次判定 DD204 = T0 且 待复核计数 > 0 | 显示 `判定 T0 · 待复核 N`——**两个降级信号同框，不二选一** |
| 会话尚未产生任何判定 | 显示 `判定 —`（灰色），**不隐藏槽位** |

**行为**

| 前提条件 + 用户动作 | 系统响应 |
|---|---|
| 任意态 + ⟨点击判定槽⟩ | 下钻至 S10 仪表盘的「判定难度分布」区（`ELMT_1102` / `ELMT_1103`）。**不弹窗** |
| 任意态 + ⟨无动作⟩ | **无系统响应**。常显元素不产生任何打扰——这是本元素的设计核心 |

**下一处能去哪**：S10 仪表盘。

**「不增加触点」的证明（对照 `kernel.md` §6）**：

| 触点 | 定义 | 本元素是否新增 |
|---|---|---|
| T1 目标锁定 | 一次性 | ❌ 不涉及 |
| T2 周度方向 | 每週 2 分钟 | ❌ 不涉及 |
| T3 喊停 | 随时 | ❌ 不涉及 |

**明确禁止的实现方式**（留给实现者当约束）：弹窗 / 模态 / 本地通知 / 推送（A4 默认零推送是产品政策）/ 红点角标 / 声音 / 震动。判定级别只在三处出现——状态行、S4 随行词标、S10 分层统计。

## 四、S1 首启引导

### ELMT_0201 · 目标锚输入

**描述**：首次运行时收集学习者想读什么（目标锚），写入账本。这是 T1 触点的唯一实现。

**显示**

| 前提条件 | 显示 |
|---|---|
| 目标锚存在且已锁定 | 不显示本屏（决策树 §一 的【引导】分支不触发） |
| 目标锚不存在 | 单栏输入 + 领域选择（哲学 / 管理）+ 难度自评起点 |

**行为**

| 前提条件 + 用户动作 | 系统响应 |
|---|---|
| 目标锚不存在 + ⟨填写并锁定⟩ | 写入目标锚对象 → 转 S2 唤起与开练，并按目标锚难度带触发首次补切 |
| 目标锚不存在 + ⟨跳过⟩ | 不提供跳过按钮——**冷启动自举【引导】分支无旁路**，否则首练无难度依据（死法 D2 难度失配） |

**下一处能去哪**：S2 唤起与开练。

## 五、S2 唤起与开练（主屏幕）

### ELMT_0301 · 续学点卡片

**描述**：呈现 journal 尾行定位到的续学点，标注来源设备与时刻（A10 的对策载体）。

**显示**

| 前提条件 | 显示 |
|---|---|
| DD706 续学点轮次为空（无轮次可定位） | 卡片不显示；S2 显示首练引导 |
| DD706 有值 且 DD703 = 已同步 | `上次会话 <相对时刻>于 <来源设备> · <轮次摘要>` + ⟨继续⟩ |
| DD706 有值 且 DD703 = 同步中 | 同上，并在卡片下方加一行 `账本同步中，以下为截至 14:20 的进度` |
| DD706 有值 且 DD703 = 同步失败 | 同上，并显示 `账本停留在 14:20（iPhone），此后的进度尚未到达本机` |
| DD706 有值 且 DD103 ≠ 本机设备 ID | 强制显示来源设备名——**跨设备续学必须知道账本来自哪台** |
| DD704 与本机最新 journal 尾行不一致 | 卡片下方加 `已按 journal 尾行重建本机缓存`（决策树 §一 的不一致分支） |

**行为**

| 前提条件 + 用户动作 | 系统响应 |
|---|---|
| 卡片可见 + ⟨继续⟩ | 转 S3 会话，`ELMT_0403` 记入「本会话由跨设备续学进入」 |
| 卡片可见 + ⟨返回⟩ | 卡片收起，S2 恢复默认档位条 |

**下一处能去哪**：S3 会话；S2 自身。

### ELMT_0302 · 今日复现条

**描述**：今日复现集的三条语块，点击直接开练（Widget 亦指向此处）。

**显示**

| 前提条件 | 显示 |
|---|---|
| 今日复现集非空 | 三行，各行显示语块文本 + 上次复现相对时刻 |
| 今日复现集为空（新的一天 / 无到期语块） | 显示 `今日无到期复现`，**不隐藏该区** |
| 语块处于复现观察期（间隔调度的中间档） | 行尾追加 `· 观察中` |

**行为**

| 前提条件 + 用户动作 | 系统响应 |
|---|---|
| 非空 + ⟨点击某语块⟩ | 转 S3 会话，该项形态置为「复现」 |
| 为空 + ⟨点击⟩ | 无系统响应；区域保持显示空态文案 |

**下一处能去哪**：S3 会话。

### ELMT_0303 · 档位条

**描述**：B0 / B2 / B5 / B15 四档唤起条，iOS 置于底部（拇指可达）。

**显示**

| 前提条件 | 显示 |
|---|---|
| 总是 | 四档全显；每档显示预估轮数 |
| 该档队列水位 ≥2 | 正常色 |
| 该档队列水位 = 1 | 降级色，档位标签后加 `· 水位不足` |
| 该档队列为空 且 无本地兜底包 | 档位置灰（仍可见，不隐藏） |
| B0 档 且 TTS 不可用 | B0 档后加 `· 无音频`。⚠️ B0 是否降级为「无音频复现题」是**未裁决的业务决策**（特性树 §六 6.1），本元素只如实标注可用性，不自行决定降级形态 |
| 已有进行中会话 | 「继续」项置顶，四档仍全显 |

**行为**

| 前提条件 + 用户动作 | 系统响应 |
